这条链路在讲什么

一段文字变成下一个字，中间要经过十几道工序。大多数讲解只挑其中一道讲透，结果是每道工序都懂一点，却说不清它们怎么串起来、哪一道最贵。

这个图解把整条链路摊成 12 步，顶部常驻的流程图告诉你在哪一步。你可以来回翻，也可以拧参数——每一步的画面会跟着变。

你能看出什么

  • 分词粒度从子词改成单字，序列长度立刻翻倍，而注意力是 O(n²)——计算量的代价是平方级的。
  • 关掉位置编码，「猫追狗」和「狗追猫」在模型眼里变成同一个东西。这是「为什么需要位置编码」最短的证明。
  • 温度不改变候选的顺序，只改变它们的相对差距；top-k 砍尾巴，top-p 按累计概率砍——三个旋钮干的是三件不同的事。
  • prefill 一次前向吃下整段提示词，decode 每个 token 一次前向。没有 KV cache 的话，总计算量是平方级的。
  • 投机解码的加速比不是「越大越好」——k 大了，后面的猜测命中率是指数衰减的。

怎么操作

  1. 点顶部流程图里的任意一步，直接跳过去；或者用下方的「上一步 / 下一步」，也可以按键盘 ← →。
  2. 每一步下方的「调一调」是这一步真正起作用的那几个参数。拖一下，画面立刻重画。
  3. 参数会被记住（下次打开还在），不会因为翻页而重置——这样才能对比「同一个参数在不同步骤里的作用」。

每一步在算什么

  • 提示词 → 分词 → 嵌入：文字先变成 id，再变成向量。模型从头到尾没见过「字」。
  • 注意力 → 归一化 → 前馈 → 层堆叠：这是主干，重复 N 层。注意力负责让 token 之间交换信息，前馈负责逐个 token 做变换。
  • 输出头 → 采样：最后一层的向量乘上词表矩阵，得到 12 万个分数，softmax 成概率，再按策略挑一个。
  • prefill → decode → KV cache → 投机解码：决定「快不快」的四步，和「准不准」无关。
